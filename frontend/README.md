# Production Line Sim frontend

Blank React + TypeScript frontend served and built with Vite.

## Development

From this directory, install dependencies with `npm install`, then start Vite with `npm run dev`.

Useful commands:

- `npm run build` — type-check and create a production build in `dist/`.
- `npm run preview` — serve the production build locally.

The existing ASP.NET Core API remains in the repository root and runs independently.
